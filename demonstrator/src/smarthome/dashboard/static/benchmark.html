Pick which smart-home architectures to compare and size the simulated home (rooms & devices), then run a fixed suite of natural-language requests through each one. The results — latency, action correctness, success rate and robustness during a cloud outage — depend on the chosen architecture (inference at the edge, in the cloud, or hybrid with local fallback). The four rooms the suite addresses are always present, so correctness stays comparable while latency grows with the home size.
